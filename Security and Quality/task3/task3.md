Ожидание :1. Вы можете указать свой собственный проект, а не пример URL-адреса.

Если книга не найдена, верните строку no book exists.
Ожидание :6. Вы можете отправить запрос DELETE/api/books/{_id} для удаления книги из коллекции. В случае успеха в ответ будет возвращена строка delete successful. Если книга не найдена, верните строку no book exists.
Ожидание :7. Вы можете отправить запрос DELETE для удаления всех книг из базы данных. В случае успеха /api/booksв ответ будет возвращена строка .complete delete successful
