Проверка цен акций
Создайте полнофункциональное JavaScript-приложение, функционально похожее на это: https://stock-price-checker.freecodecamp.rocks/ .

Поскольку для всех надежных API для проверки цен на акции требуется ключ API, мы разработали обходное решение. Используйте https://stock-price-checker-proxy.freecodecamp.rocks/ , чтобы получать актуальную информацию о ценах на акции без необходимости регистрации и получения собственного ключа.

Ожидание :1. Вы можете указать свой собственный проект, а не пример URL-адреса.
Ожидание :2. Вам следует настроить политики безопасности контента таким образом, чтобы разрешалась загрузка скриптов и CSS только с вашего сервера.
