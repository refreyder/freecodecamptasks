Introduction

Python is a high-level, interpreted programming language known for its clear syntax and readability.

It supports multiple programming paradigms, including procedural, object-oriented, and functional programming.

print("Hello, World!")
  • Easy to read and write
  • Extensive standard library
  • Cross-platform compatibility
Variables and Types

Variables in Python are created when you assign a value to them, without needing explicit type declarations.

Common built-in types include integers, floating-point numbers, strings, and booleans.

count = 42 price = 19.99
  • int for whole numbers
  • float for decimal numbers
  • str for text sequences
Control Flow

Conditional statements allow your program to execute different branches of code based on boolean expressions.

Loops let you repeat a block of code multiple times over a sequence or while a condition holds true.

if x > 0: print("Positive")
  • if, elif, and else statements
  • for loops for iterating over sequences
  • while loops for condition-based repetition
Functions

Functions are reusable blocks of code defined with the def keyword that perform a specific task.

They can accept parameters and return values using the return statement.

def greet(name): return f"Hello, {name}"
  • Positional and keyword arguments
  • Default parameter values
Data Structures

Python provides built-in data structures to organize and store collections of data efficiently.

Choosing the right structure depends on whether you need ordering, mutability, or key-based lookups.

items = ["apple", "banana", "cherry"]
  • Lists for ordered, mutable collections
  • Tuples for ordered, immutable collections
  • Dictionaries for key-value mappings
