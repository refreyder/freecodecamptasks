Создать страницу технической документации
Цель: Создать приложение, функционально аналогичное https://technical-documentation-page.freecodecamp.rocks . Не копируйте этот демонстрационный проект .

Пользовательские истории:

Вы можете увидеть mainэлемент с соответствующим тегом <div> id="main-doc", который содержит основное содержимое страницы (техническую документацию).
Внутри #main-docэлемента вы увидите несколько sectionэлементов, каждый из которых имеет класс main-section. Должно быть как минимум пять таких элементов.
Первым элементом в каждом из них .main-sectionдолжен быть headerэлемент, содержащий текст, описывающий тему данного раздела.
Каждый sectionэлемент с классом main-sectionдолжен также иметь атрибут id, соответствующий тексту каждого headerсодержащегося в нем элемента. Все пробелы следует заменять подчеркиваниями (например, раздел, содержащий заголовок «JavaScript и Java», должен иметь соответствующий атрибут id="JavaScript_and_Java").
Элементы .main-sectionдолжны содержать в общей сложности не менее десяти pэлементов (не каждый из них по отдельности).
Элементы .main-sectionдолжны содержать codeв общей сложности не менее пяти элементов (не каждый из них по отдельности).
Элементы .main-sectionдолжны содержать не менее пяти liпунктов в общей сложности (не каждый по отдельности).
Вы можете увидеть navэлемент с соответствующимid="navbar"
Элемент панели навигации должен содержать один headerэлемент с текстом, описывающим тему технической документации.
Кроме того, панель навигации должна содержать aэлементы ссылок ( ) с классом nav-link. Для каждого элемента с классом должен быть отдельный элемент.main-section
Элемент headerдолжен #navbarрасполагаться перед любыми aэлементами ссылок ( ) в навигационной панели.
Каждый элемент с классом nav-linkдолжен содержать текст, соответствующий тексту headerвнутри него section(например, если у вас есть раздел/заголовок «Hello world», ваша панель навигации должна содержать элемент, содержащий текст «Hello world»).
При нажатии на элемент навигационной панели страница должна перейти к соответствующему разделу этого #main-docэлемента (например, если вы нажмете на .nav-linkэлемент, содержащий текст "Hello world", страница перейдет к sectionэлементу с таким же идентификатором и будет содержать соответствующий заголовок).
На устройствах стандартного размера (ноутбуках, настольных компьютерах) элемент id="navbar"должен отображаться в левой части экрана и всегда быть виден пользователю.
В вашей технической документации следует использовать как минимум один медиа-запрос.
