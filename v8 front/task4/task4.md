Создайте целевую страницу продукта.
Цель: Создать приложение, функционально аналогичное https://product-landing-page.freecodecamp.rocks . Не копируйте этот демонстрационный проект .

Пользовательские истории:

На целевой странице вашего продукта должен быть headerэлемент с соответствующимid="header"
Внутри элемента вы увидите изображение headerс соответствующим id="header-img"(здесь хорошо бы смотрелся логотип).
Внутри #headerэлемента вы можете увидеть navэлемент с соответствующимid="nav-bar"
Внутри элемента можно увидеть как минимум три кликабельных элемента nav, каждый из которых имеет класс.nav-link
При нажатии на .nav-linkкнопку в navэлементе вы переходите в соответствующий раздел целевой страницы.
Вы можете посмотреть встроенное видео о продукте с помощьюid="video"
На вашей целевой странице есть formэлемент с соответствующимid="form"
В форме есть inputполе , id="email"куда можно ввести адрес электронной почты.
В #emailполе ввода должен быть текст-заполнитель, чтобы пользователи понимали, для чего это поле предназначено.
Поле #emailввода использует HTML5-валидацию для подтверждения того, что введенный текст является адресом электронной почты.
Внутри формы есть кнопка отправки inputс соответствующим сопроводительным словом.id="submit"
При нажатии на #submitэлемент электронное письмо отправляется на статическую страницу (используйте этот примерный URL: https://www.freecodecamp.com/email-submit).
Панель навигации всегда должна располагаться в верхней части области просмотра.
На целевой странице вашего продукта должен быть как минимум один медиа-запрос.
На целевой странице вашего продукта следует хотя бы один раз использовать CSS flexbox.
Выполните пользовательские истории и пройдите все тесты ниже, чтобы завершить этот проект. Придайте ему свой собственный стиль. Удачного кодирования!

Примечание: Обязательно добавьте <link rel="stylesheet" href="styles.css">HTML-код для подключения таблицы стилей и применения CSS.
