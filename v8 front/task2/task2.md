Создать страницу памяти
Цель: Создать приложение, функционально аналогичное https://tribute-page.freecodecamp.rocks . Не копируйте этот демонстрационный проект .

Пользовательские истории:

На вашей странице памяти должен быть mainэлемент с соответствующим idзначением main, который содержит все остальные элементы.
Вы должны увидеть элемент с idатрибутом `<div>` title, содержащий строку (т.е. текст), описывающую тему страницы памяти (например, «Доктор Норман Борлауг»).
Вы должны увидеть либо элемент figure, либо divэлемент с idатрибутомimg-div
Внутри #img-divэлемента вы должны увидеть imgэлемент с соответствующим элементом.id="image"
Внутри #img-divэлемента вы должны увидеть элемент с соответствующим id="img-caption"содержимым, содержащим текстовое описание изображения, показанного в#img-div
Вы должны увидеть элемент с соответствующим тегом id="tribute-info", который содержит текстовое содержимое, описывающее тему страницы памяти.
Вы должны увидеть aэлемент с соответствующей id="tribute-link"ссылкой, которая ведет на внешний сайт, содержащий дополнительную информацию по теме страницы, посвященной памяти. ПОДСКАЗКА: Чтобы ссылка открывалась в новой вкладке, необходимо присвоить элементу атрибут `<link>` targetи установить его значение на `<link>`._blank
Для адаптивного изменения размера элемента относительно ширины родительского элемента, без превышения его исходного размера, следует использовать свойства ` #imageand` max-width.height
Ваш imgэлемент должен быть центрирован внутри родительского элемента.
Выполните пользовательские истории и пройдите все тесты ниже, чтобы завершить этот проект. Придайте ему свой собственный стиль. Удачного кодирования!

Примечание: Обязательно добавьте <link rel="stylesheet" href="styles.css">HTML-код для подключения таблицы стилей и применения CSS.
