Создать форму опроса
Цель: Создать приложение, функционально аналогичное https://survey-form.freecodecamp.rocks . Не копируйте этот демонстрационный проект .

Пользовательские истории:

Заголовок страницы должен быть расположен в h1элементе с атрибутом id`of`.title
Краткое пояснение должно быть размещено в pэлементе с атрибутом id`of`.description
У вас должен быть formэлемент с idатрибутомsurvey-form
Внутри элемента формы вам необходимо ввести свое имя в inputполе, которое имеет поля id"of" nameи " typeof".text
Внутри элемента формы вам необходимо ввести свой адрес электронной почты в inputполе, имеющее idзначениеemail
Если вы введете адрес электронной почты с неправильным форматированием, вы увидите ошибку проверки HTML5.
Внутри формы вы можете ввести число в inputполе, которое имеет idзначениеnumber
Ввод чисел не должен принимать нечисловые значения, либо путем запрета их ввода, либо путем отображения ошибки валидации HTML5 (в зависимости от вашего браузера).
Если вы введете числа, выходящие за пределы диапазона ввода чисел, определенного атрибутами ` minand` и `or` max, вы увидите ошибку валидации HTML5.
Для полей ввода имени, электронной почты и номера телефона в форме отображаются соответствующие labelэлементы, описывающие назначение каждого поля с помощью следующих идентификаторов: id="name-label", id="email-label", иid="number-label"
В полях ввода имени, электронной почты и номера телефона отображается текст-заполнитель, содержащий описание или инструкции для каждого поля.
Внутри элемента формы должен находиться selectвыпадающий список с вариантами idвыбора dropdownи как минимум двумя вариантами.
Внутри элемента формы можно выбрать вариант из группы, состоящей как минимум из двух переключателей, сгруппированных с помощью nameатрибута.
Внутри элемента формы можно выбрать несколько полей из ряда флажков, каждый из которых должен иметь valueатрибут.
Внутри элемента формы отображается поле textareaдля дополнительных комментариев.
Внутри элемента формы находится кнопка idдля submitотправки всех введенных данных.
Выполните пользовательские истории и пройдите все тесты ниже, чтобы завершить этот проект. Придайте ему свой собственный стиль. Удачного кодирования!

Примечание: Обязательно добавьте <link rel="stylesheet" href="styles.css">HTML-код для подключения таблицы стилей и применения CSS.
