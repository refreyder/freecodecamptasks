Визуализация данных с помощью тепловой карты.
Цель: Создать приложение, функционально похожее на это: https://heat-map.freecodecamp.rocks .

Выполните указанные ниже пользовательские истории и добейтесь успешного прохождения всех тестов. Используйте любые необходимые библиотеки или API. Придайте проекту свой собственный стиль.

Вы можете использовать HTML, JavaScript, CSS и библиотеку визуализации D3 на основе SVG. Необходимые элементы DOM запрашиваются в момент каждого теста. Если вы используете фронтенд-фреймворк (например, Vue), результаты теста могут быть неточными для динамического контента. Мы надеемся в будущем это исправить, но в настоящее время эти фреймворки не поддерживаются для проектов D3.

Пользовательская история №1: Моя тепловая карта должна иметь заголовок с соответствующим id="title".

Пользовательская история №2: Моя тепловая карта должна иметь описание с соответствующим id="description".

Пользовательская история №3: Моя тепловая карта должна иметь ось X с соответствующим значением id="x-axis".

Пользовательская история №4: Моя тепловая карта должна иметь ось Y с соответствующим значением id="y-axis".

Пользовательская история №5: Моя тепловая карта должна содержать rectэлементы class="cell", которые представляют данные.

Пользовательская история №6: Для заливки ячеек должно использоваться как минимум 4 разных цвета.

Пользовательская история №7: Каждая ячейка будет иметь свойства data-month, data-year, data-tempсодержащие соответствующие им значения month, year, и .temperature

Пользовательская история №8: Значение data-monthзапятой data-yearв каждой ячейке должно находиться в пределах диапазона данных.

Пользовательская история №9: На моей тепловой карте ячейки должны совпадать с соответствующим месяцем по оси Y.

Пользовательская история № 10: На моей тепловой карте ячейки должны совпадать с соответствующим годом по оси X.

Пользовательская история № 11: На моей тепловой карте должно быть несколько меток на оси Y с полным названием месяца.

Пользовательская история № 12: На моей тепловой карте должно быть несколько меток на оси X, отражающих годы с 1754 по 2015.

Пользовательская история № 13: Моя тепловая карта должна иметь легенду с соответствующим id="legend".

Пользовательская история № 14: Моя легенда должна содержать rectэлементы.

Пользовательская история № 15: Элементы rectв легенде должны использовать как минимум 4 разных цвета заливки.

Пользовательская история № 16: При наведении курсора мыши на определенную область появляется всплывающая подсказка с соответствующей id="tooltip"информацией об этой области.

Пользовательская история № 17: Моя всплывающая подсказка должна иметь data-yearсвойство, соответствующее data-yearактивной области.
