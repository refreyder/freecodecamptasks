Вы можете использовать HTML, JavaScript, CSS и библиотеку визуализации D3 на основе SVG. Для тестов требуется генерация осей с помощью свойства `axis` в D3, которое автоматически создает деления вдоль оси. Эти деления необходимы для прохождения тестов D3, поскольку их положение используется для определения выравнивания элементов графика. Информацию о генерации осей вы найдете по адресу https://d3js.org/d3-axis . Необходимые элементы DOM запрашиваются в момент каждого теста. Если вы используете фронтенд-фреймворк (например, Vue), результаты тестов могут быть неточными для динамического контента. Мы надеемся в будущем это исправить, но в настоящее время эти фреймворки не поддерживаются для проектов D3.
