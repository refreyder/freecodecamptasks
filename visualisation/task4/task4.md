Визуализация данных с помощью хорплетной карты
Цель: Создать приложение, функционально похожее на это: https://choropleth-map.freecodecamp.rocks .

Выполните указанные ниже пользовательские истории и добейтесь успешного прохождения всех тестов. Используйте любые необходимые библиотеки или API. Придайте проекту свой собственный стиль.

Вы можете использовать HTML, JavaScript, CSS и библиотеку визуализации D3 на основе SVG. Необходимые элементы DOM запрашиваются в момент каждого теста. Если вы используете фронтенд-фреймворк (например, Vue), результаты теста могут быть неточными для динамического контента. Мы надеемся в будущем это исправить, но в настоящее время эти фреймворки не поддерживаются для проектов D3.

Пользовательская история №1: Моя хорплетная карта должна иметь заголовок с соответствующим id="title".

Пользовательская история №2: Моя хорплетная карта должна содержать элемент описания с соответствующим id="description".

Пользовательская история №3: Моя картограмма должна содержать class="county"данные по округам, для каждого из которых соответствует отдельный элемент.

Пользовательская задача №4: Для обозначения округов должно использоваться как минимум 4 разных цвета заливки.

Пользовательская история № 5: В каждом из моих округов должны быть data-fipsсвойства, data-educationсодержащие соответствующие им fipsзначения education.

Пользовательская история №6: Моя картограмма должна содержать данные по каждому округу для каждой предоставленной точки данных.

Пользовательская история №7: Округа должны иметь значения data-fips, data-educationсоответствующие выборочным данным.

Пользовательская история №8: Моя хорплетная карта должна иметь легенду с соответствующим id="legend".

Пользовательская задача №9: Для легенды следует использовать как минимум 4 разных цвета заливки.

Пользовательская история № 10: При наведении курсора мыши на определенную область появляется всплывающая подсказка с соответствующей id="tooltip"информацией об этой области.

Пользовательская история № 11: Моя всплывающая подсказка должна иметь data-educationсвойство, соответствующее data-educationактивной области.
