Создать средство предварительного просмотра Markdown

Цель: Создать приложение, функционально похожее на это: https://markdown-previewer.freecodecamp.rocks/ .

Выполните указанные ниже пользовательские истории и добейтесь успешного прохождения всех тестов. Используйте любые необходимые библиотеки или API. Придайте проекту свой собственный стиль.

Для выполнения этого проекта вы можете использовать любую комбинацию HTML, JavaScript, CSS, Bootstrap, SASS, React, Redux и jQuery. Рекомендуется использовать фронтенд-фреймворк (например, React), поскольку этот раздел посвящен изучению фронтенд-фреймворков. Использование дополнительных технологий, не перечисленных выше, не рекомендуется и осуществляется на ваш собственный риск. Мы рассматриваем возможность поддержки других фронтенд-фреймворков, таких как Angular и Vue, но в настоящее время они не поддерживаются. Мы примем и постараемся исправить все сообщения об ошибках, связанные с использованием предложенного для этого проекта технологического стека. Удачного кодирования!

Пользовательская история №1: Я вижу textareaэлемент с соответствующим id="editor".

Пользовательская история №2: Я вижу элемент с соответствующим id="preview".

Пользовательская история №3: Когда я ввожу текст в #editorэлемент, #previewэлемент обновляется по мере ввода, отображая содержимое текстового поля.

Пользовательская история №4: Когда я ввожу Markdown-код, адаптированный под GitHub, в #editorэлемент, текст отображается как HTML внутри #previewэлемента по мере ввода (ПОДСКАЗКА: Вам не нужно самостоятельно анализировать Markdown — для этого можно импортировать библиотеку Marked: https://cdnjs.com/libraries/marked ).

Пользовательская история №5: При первой загрузке окна предварительного просмотра Markdown текст по умолчанию в #editorполе должен содержать корректный Markdown, представляющий как минимум один из следующих элементов: заголовок (размер H1), подзаголовок (размер H2), ссылка, встроенный код, блок кода, элемент списка, цитата, изображение и выделенный жирным шрифтом текст.

Пользовательская история №6: При первой загрузке окна предварительного просмотра Markdown, стандартный Markdown в #editorполе должен отображаться как HTML в #previewэлементе.
