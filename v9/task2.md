Создайте приложение для составления бюджета.
В этой лабораторной работе вы создадите простое приложение для управления бюджетом, которое будет отслеживать расходы по различным категориям и отображать относительный процент расходов на графике.

Цель: Выполнить приведенные ниже пользовательские истории и добиться успешного прохождения всех тестов для завершения лабораторной работы.

Пользовательские истории:

Вам нужен Categoryкласс, который принимает имя в качестве аргумента.

Класс Categoryдолжен иметь атрибут экземпляра ledger, представляющий собой список, содержащий перечень транзакций.

Класс Categoryдолжен содержать следующие методы:

Метод deposit, принимающий значение amount и необязательное описание. Если описание не указано, по умолчанию должно быть пустое значение. Метод должен добавлять объект в ledgerсписок в виде {'amount': amount, 'description': description}.
Метод withdraw, принимающий сумму и необязательное описание (по умолчанию — пустая строка). Метод должен сохранять ledgerпереданную сумму как отрицательное число и возвращать значение, Trueесли вывод средств прошел успешно, и Falseзначение в противном случае.
Метод get_balance, возвращающий текущий баланс категории на основе ledger.
Метод transfer, который принимает сумму и другой Categoryэкземпляр, снимает сумму с описанием Transfer to [Destination]и вносит её в другую категорию с описанием Transfer from [Source], где [Destination]и [Source]должны быть заменены именами категорий назначения и источника. Метод должен возвращать значение, Trueесли перевод успешен, и Falseзначение в противном случае.
Метод check_funds, который принимает сумму и возвращает значение, Falseесли она превышает баланс, или значение, превышающее Trueего в противном случае. Этот метод должен использоваться как методом, так withdrawи transferметодом.
При Categoryвыводе объекта на экран должно происходить следующее:

Отобразить заголовок длиной 30 символов, при этом название категории будет выровнено по центру между *символами.
Укажите для каждой ledgerзаписи не более 23 символов описания, выровненного по левому краю, и сумму, выровненную по правому краю (два знака после запятой, максимум 7 символов).
Отобразить заключительную строку Total: [balance], где [balance]следует заменить итоговой суммой по категории.
Вот пример использования:

food = Category('Food')
food.deposit(1000, 'initial deposit')
food.withdraw(10.15, 'groceries')
food.withdraw(15.89, 'restaurant and more food for dessert')
clothing = Category('Clothing')
food.transfer(50, clothing)
print(food)

Вам следует создать функцию вне Categoryкласса create_spend_chart(categories), которая принимает список категорий и возвращает строку с гистограммой. Для построения диаграммы:

Начните с заголовка Percentage spent by category.
Рассчитывайте проценты только от снятия средств, а не от внесения депозитов. Процент должен представлять собой отношение суммы, потраченной на каждую категорию, к общей сумме, потраченной на все категории (округлено до ближайших 10 в меньшую сторону).
Пронумеруйте ось Y снизу 100вверх 0с шагом 10.
Используйте oсимволы для обозначения полос.
После последней черточки добавьте горизонтальную линию на два пробела.
Названия категорий следует писать вертикально под полосой.
Данная функция будет протестирована с использованием до четырех категорий.
