Создайте калькулятор площади многоугольника
В этом проекте вы будете использовать объектно-ориентированное программирование для создания Rectangleкласса и Squareкласса. SquareКласс должен быть подклассом Rectangleи наследовать его методы и атрибуты.

Цель: Выполнить приведенные ниже пользовательские истории и добиться успешного прохождения всех тестов для завершения лабораторной работы.

Пользовательские истории:

Вам следует создать Rectangleкласс.

При Rectangleсоздании объекта его следует инициализировать widthатрибутами height. Класс также должен содержать следующие методы:

set_width: Задает ширину прямоугольника.
set_height: Задает высоту прямоугольника.
get_areaОбласть возврата ( ширина × высота
 ).
get_perimeter: Возвращает периметр 2 ( ширина + высота )
 .
get_diagonal: Возвращает диагональ ширина2+высота2−−−−−−−−−−−−−−√
 .
get_pictureФункция возвращает строку, представляющую фигуру с помощью строк *. Количество строк должно быть равно высоте, а количество символов *в каждой строке — ширине. \nВ конце каждой строки должна быть новая строка ( ). Если ширина или высота больше 50, функция вернет строку:Too big for picture.
get_amount_insideФункция принимает в качестве аргумента другую фигуру (квадрат или прямоугольник). Возвращает количество раз, сколько переданная фигура может поместиться внутри другой фигуры (без поворотов). Например, два квадрата со сторонами 4могут поместиться внутри прямоугольника шириной 4и высотой 8.
Если экземпляр объекта a Rectangleпредставлен в виде строки, он должен выглядеть так: Rectangle(width=5, height=10).

Вам следует создать Squareкласс, который наследует данный класс Rectangle.

При Squareсоздании объекта его следует инициализировать одной длиной стороны. Метод __init__должен хранить длину стороны как в атрибуте, так widthи heightв атрибуте класса Rectangle.

Класс Squareдолжен содержать следующие методы:

set_width: Переопределяет set_widthметод класса Rectangle. Он должен устанавливать ширину и высоту равными длине стороны.
set_height: Переопределяет set_heightметод класса Rectangle. Он должен устанавливать ширину и высоту равными длине стороны.
set_side: Устанавливает высоту и ширину квадрата равными длине стороны.
Класс Squareдолжен иметь доступ к Rectangleметодам класса.

Если экземпляр объекта a Squareпредставлен в виде строки, он должен выглядеть так: Square(side=9).

Пример использования
rect = Rectangle(10, 5)
print(rect.get_area())
rect.set_height(3)
print(rect.get_perimeter())
print(rect)
print(rect.get_picture())

sq = Square(9)
print(sq.get_area())
sq.set_side(4)
print(sq.get_diagonal())
print(sq)
print(sq.get_picture())

rect.set_height(8)
rect.set_width(16)
print(rect.get_amount_inside(sq))
