Создать хеш-таблицу
В этой лабораторной работе вы создадите хеш-таблицу с нуля. Хеш-таблица — это структура данных, которая хранит пары ключ-значение. Хеш-таблица работает, принимая ключ в качестве входных данных, а затем хешируя этот ключ в соответствии с определенной хеш-функцией.

Для целей этой лабораторной работы хеш-функция будет простой: она будет суммировать кодовые точки Unicode каждого символа в ключе. Полученное хеш-значение затем будет использоваться в качестве фактического ключа для хранения соответствующего значения. Это же хеш-значение будет использоваться для извлечения и удаления значения, связанного с ключом.

Цель: Выполнить приведенные ниже пользовательские истории и добиться успешного прохождения всех тестов для завершения лабораторной работы.

Пользовательские истории:

При создании нового экземпляра класса следует определить класс HashTableс collectionатрибутом, инициализированным пустым словарем . Словарь должен хранить пары ключ-значение на основе хешированного значения ключа.HashTablecollection

Класс HashTableдолжен иметь четыре метода экземпляра: hash, add, remove, и lookup.

Данный hashметод должен:

Принимает строку в качестве параметра.
Возвращает хешированное значение, вычисленное как сумма кодовых точек Юникода каждого символа в строке. Вы можете использовать эту ordфункцию для получения кодовой точки каждого символа.
Данный addметод должен:

Примите два аргумента, представляющих пару ключ-значение, и вычислите хеш ключа.
Используйте вычисленное хеш-значение в качестве ключа для хранения словаря, содержащего пары ключ-значение collection.
Если несколько ключей дают одинаковое хеш-значение, то их пары ключ-значение следует хранить в существующем вложенном словаре под тем же хеш-значением.
Данный removeметод должен:

Принимает ключ в качестве аргумента и вычисляет его хеш.
Убедитесь, что ключ существует в коллекции.
Удалите соответствующую пару ключ-значение из хеш-таблицы.
Если ключ отсутствует в коллекции, это не должно вызывать ошибку и ничего не должно удаляться.
Данный lookupметод должен:

В качестве аргумента возьмем ключ.
Вычислите хеш ключа и верните соответствующее значение, хранящееся в хеш-таблице.
Если ключ отсутствует в коллекции, функция должна вернуть значение None.
