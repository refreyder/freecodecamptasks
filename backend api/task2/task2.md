Тесты:
Ожидание :1. Вам следует указать свой собственный проект, а не пример URL-адреса.
Ожидание :2. Запрос /api/whoami должен вернуть JSON-объект, содержащий ваш IP-адрес в качестве ipaddress ключа.
Ожидание :3. Запрос /api/whoami должен вернуть JSON-объект, в language ключе которого указан предпочитаемый вами язык.
Ожидание :4. Запрос /api/whoami должен возвращать JSON-объект, содержащий ваше программное обеспечение в качестве software ключа.
