ПОДСКАЗКА: Не забудьте использовать промежуточное ПО для анализа тела POST-запроса. Также вы можете использовать функцию dns.lookup(host, cb) из dns основного модуля для проверки отправленного URL-адреса.

Тесты:
Ожидание :1. Вам следует указать свой собственный проект, а не пример URL-адреса.
Ожидание :2. Вы можете отправить URL-адрес методом POST /api/shorturl и получить JSON-ответ со свойствами original_url и short_url. Вот пример: {original_url : 'https://freeCodeCamp.org', short_url : 1}
Ожидание :3. При посещении сайта /api/shorturl/<short_url> вы будете перенаправлены на исходный URL-адрес.
Ожидание :4. Если вы передадите недействительный URL-адрес, не соответствующий допустимому http://www.example.com формату, JSON-ответ будет содержать следующее: { error: 'invalid url' }
