Проект по созданию калькулятора вероятностей
Предположим, в шляпе находятся 5 синих шаров, 4 красных шара и 2 зеленых шара. Какова вероятность того, что при случайном вытягивании 4 шаров окажется хотя бы 1 красный шар и 2 зеленых шара? Хотя вероятность можно вычислить с помощью высшей математики, более простой способ — написать программу для проведения большого количества экспериментов с целью приблизительной оценки вероятности.

В рамках этого проекта вам предстоит написать программу для определения приблизительной вероятности случайного вытягивания определённых шаров из шляпы.

Сначала создайте Hatкласс в main.py. Класс должен принимать переменное количество аргументов, указывающих количество шаров каждого цвета в шляпе. Например, объект класса можно создать любым из следующих способов:

hat1 = Hat(yellow=3, blue=2, green=6)
hat2 = Hat(red=5, orange=4)
hat3 = Hat(red=5, orange=4, black=1, blue=0, pink=2, striped=9)
Шляпа всегда будет создана как минимум с одним мячом. Аргументы, передаваемые в объект шляпы при создании, должны быть преобразованы в contentsпеременную экземпляра. contentsдолжна представлять собой список строк, содержащий по одному элементу для каждого мяча в шляпе. Каждый элемент списка должен быть названием цвета, представляющим отдельный мяч этого цвета. Например, если ваша шляпа — {'red': 2, 'blue': 1}, contentsто должно быть ['red', 'red', 'blue'].

Класс Hatдолжен иметь drawметод, принимающий аргумент, указывающий количество шаров, которые нужно вытащить из шляпы. Этот метод должен случайным образом удалять шары из шляпы contentsи возвращать их в виде списка строк. Шары не должны возвращаться в шляпу во время вытаскивания, подобно эксперименту с урной, без возвращения. Если количество шаров для вытаскивания превышает доступное количество, вернуть все шары.

Далее создайте experimentфункцию внутри класса main.py(не внутри него Hat). Эта функция должна принимать следующие аргументы:

hatОбъект шляпы, содержащий мячи, которые должны быть скопированы внутрь функции.
expected_balls: Объект, указывающий точную группу шаров, которые следует попытаться вытащить из шляпы в ходе эксперимента. Например, чтобы определить вероятность вытащить из шляпы 2 синих шара и 1 красный шар, установите expected_ballsзначение {'blue':2, 'red':1}.
num_balls_drawn: Количество шаров, которые нужно вытащить из шляпы в каждом эксперименте.
num_experiments: Количество экспериментов, которые необходимо провести. (Чем больше экспериментов будет проведено, тем точнее будет приблизительная вероятность.)
Функция experimentдолжна возвращать вероятность.

Например, если вы хотите определить вероятность получения как минимум двух красных и одного зеленого шара при вытягивании пяти шаров из шляпы, содержащей шесть черных, четыре красных и три зеленых шара. Для этого вы проведете Nэксперименты, посчитаете, сколько раз Mвы получили как минимум два красных и один зеленый шар, и оцените вероятность как M/N. Каждый эксперимент состоит в том, чтобы начать со шляпы, содержащей указанные шары, вытянуть несколько шаров и проверить, получили ли вы шары, которые пытались вытянуть.

Вот как можно вызвать experimentфункцию, основываясь на приведенном выше примере с 2000 экспериментами:

hat = Hat(black=6, red=4, green=3)
probability = experiment(hat=hat,
                  expected_balls={'red':2,'green':1},
                  num_balls_drawn=5,
                  num_experiments=2000)
В результате получится что-то подобное:

0.356
Поскольку расчеты основаны на случайных выборках, вероятность будет немного отличаться при каждом запуске кода.

Подсказка: Рекомендуется использовать модули, уже импортированные в начале файла. Не инициализируйте начальное значение генератора случайных чисел внутри файла.

Примечание: для просмотра более подробного вывода результатов тестов откройте консоль браузера, нажав клавишу F12.
