Создать проект калькулятора времени
Напишите функцию add_time, которая принимает два обязательных параметра и один необязательный параметр:

Время начала в 12-часовом формате (оканчивающееся на AM или PM).
продолжительность времени, указывающая количество часов и минут.
(необязательно) начальный день недели, регистр не имеет значения
Функция должна сложить время выполнения с временем начала и вернуть результат.

Если результат будет получен на следующий день, он должен отобразиться (next day)после указанного времени. Если результат будет получен более чем через один день, он должен отобразиться (n days later)после указанного времени, где "n" — количество дней.

Если функции передается необязательный параметр начального дня недели, то в выходных данных должен отображаться день недели, соответствующий результату. День недели в выходных данных должен располагаться после времени и перед количеством дней.

Ниже приведены примеры различных случаев, которые должна обрабатывать эта функция. Обратите особое внимание на пробелы и знаки препинания в результатах.

add_time('3:00 PM', '3:10')
# Returns: 6:10 PM

add_time('11:30 AM', '2:32', 'Monday')
# Returns: 2:02 PM, Monday

add_time('11:43 AM', '00:20')
# Returns: 12:03 PM

add_time('10:10 PM', '3:30')
# Returns: 1:40 AM (next day)

add_time('11:43 PM', '24:20', 'tueSday')
# Returns: 12:03 AM, Thursday (2 days later)

add_time('6:30 PM', '205:12')
# Returns: 7:42 AM (9 days later)
Не импортируйте никакие библиотеки Python. Предположите, что время начала является допустимым. Минуты во времени продолжительности будут целым числом меньше 60, а час может быть любым целым числом.

Примечание: для просмотра более подробного вывода результатов тестов откройте консоль браузера, нажав клавишу F12.
